三分钟快速上手

只需简单几步，即可在 Chrome / Edge 中开启观影新体验

1

下载扩展安装包

前往 GitHub Releases 下载最新的 cowatcher-extension.zip，并在本地解压缩。

2

打开开发者模式并加载

在浏览器地址栏输入 chrome://extensions/，勾选右上角的 开发者模式 (Developer Mode)，点击 加载已解压的扩展程序 (Load unpacked)，选中解压出来的文件夹。

3

选择模型并开启观影

点击浏览器右上角 CoWatcher 插件图标，选择默认免费翻译、本地 Ollama 或填写云端 API Key，打开 Netflix、TVer 或 YouTube 播放页按下 Alt + T 即可立即享受！
