1. 🌟 我该怎么选择适合我的翻译方式？ ​

CoWatcher 提供多种翻译接入方式，不管你是追剧高中生还是技术极客，都能找到最舒适的姿势：

方案适合人群费用特点配置难度
开箱即用免费翻译普通追剧党、学生党完全免费装好插件直接能用，无需额外设置⭐ 零门槛
电脑本地显卡 (Ollama)拥有独立显卡 (如 GTX 1660 / RTX 2060 以上)完全免费保护隐私、不耗网络流量、响应速度快⭐⭐ 需安装 Ollama
顶尖云端模型 (OpenRouter)追求极致地道翻译、人名梗句零出戏按用量计费 (极便宜)支持 DeepSeek、Claude、Gemini 等超聪明模型⭐⭐ 需填入 API Key
  • 👉 查看 Ollama 本地部署教程
  • 👉 查看 OpenRouter 云端 API 配置教程

2. ⚡ 最常用快捷操作速查 ​

在播放视频时，你只需要掌握以下几个高频操作：

  • Alt + T：全局开关 AI 双语字幕，随时一键唤出或隐藏。

  • 双语上下层互换：在控制面板中随时将翻译置于主字幕或副字幕，灵活适应母语理解或外语听力精读。

  • 生词点击与查询：遇到不懂的台词单词，直接点击即可查看释义，并支持一键收录进 Anki 单词本。

  • 跨集人名自动记忆：第 1 集识别出的角色名和昵称，自动继承到第 2 集，追连载剧再也不怕译名乱变！
