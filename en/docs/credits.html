📖 Free Dictionary Data Sources & Public APIs ​

We gratefully acknowledge the following free and open-access dictionary datasets, public APIs, and lexical resources powering CoWatcher's vocabulary lookup and language immersion:

  • Wiktionary REST API (Wikimedia Foundation)
    • License: CC BY-SA 3.0 / CC BY-SA 4.0
    • Multilingual lexical definitions, grammatical inflections, and bilingual translations across Spanish, French, German, and international languages.
  • JMdict & Kanjidic2 / Jisho.org (Electronic Dictionary Research and Development Group - EDRDG)
    • License: EDRDG Licence
    • Authentic Japanese dictionary entries, kanji breakdowns, readings, and English definitions.
  • Free Dictionary API
    • License: Open Community API
    • Comprehensive English definitions, parts of speech, phonetics, audio pronunciations, and etymology.
  • Zhuyin Phonetics Dataset
    • License: CC BY-ND 3.0 TW
    • MOE Mandarin Chinese Dictionary Public Licensing Network - Zhuyin Phonetics Open Dataset
  • Youdao Dictionary & Naver Dictionary Web Endpoints
    • Notice: Public Web APIs
    • Multilingual dictionary lookup endpoints for Chinese, Korean, and Japanese bilingual learners.

⚙️ Open Source NLP, Linguistics & Phonetic Engines ​

CoWatcher relies on the following open-source projects for zero-dependency client-side word segmentation, lemmatization, and phonetic transliteration:

  • kuroshiro & kuromoji.js
    • License: MIT / Apache 2.0
    • Japanese morphological analysis, word segmentation, and furigana/hiragana generation.
  • pinyin-pro & pinyin-zhuyin
    • License: MIT
    • High-precision Chinese Hanzi to Pinyin and Bopomofo (Zhuyin) phonetic converter.
  • romaja & koroman
    • License: MIT
    • Korean Hangul Revised Romanization and phonetic transliteration engine.
  • wink-lemmatizer
    • License: MIT
    • Standard English morphological lemmatizer for nouns, verbs, and adjectives.
